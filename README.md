# 🍱 Food Waste Redistribution Platform

A web-based platform that connects food donors (restaurants, bakeries, etc.) with NGOs to redistribute surplus food and reduce food waste.

## 🚀 Live Demo

**[Click here to access the Food Waste Redistribution Platform](https://foodwasteredistribution-ivuxcx9mhjvr5qkxutwf69.streamlit.app/)**

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Git & GitHub

## ✨ Key Features

- User registration and login for donors and collectors.
- Role-based dashboards.
- Add, view, edit, and delete food donations.
- Collectors can view and claim available donations.
- Track donation statuses: Available, Claimed, and Collected.
- Min-Heap-based prioritization of donations by expiry deadline.
- Ownership validation to prevent unauthorized modifications.

## ▶️ Run Locally

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```
2. Navigate to the project directory:
   ```bash
   cd FoodWasteRedistribution
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Start the application:
   ```bash
   streamlit run app.py
   ```
